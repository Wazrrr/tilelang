here is the sturcture of experiments. this experiments is conducted by 5 kernels, gemm, grouped_gemm, Flashattention, kda and FP8 GEMM. they share the same code structure below. use gemm as an example.
in gemm/, it contains system and tiletune two main bash folders. in system, there is python file that can run three system optimizations in advanced autotuning ablation and combined. in tiletune, it contains a run that only tun tiletune itself.
for the baselines of tiletune, it preserve the result of brute-force, carver and xgboost trained model, ranking results, etc. in the kernel folder without maintaining the archive. while do the comparison with tiletune, only check whether the config space is matched or not. which is the only factor would affect the results in baselines.
